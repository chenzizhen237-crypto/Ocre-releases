# Ocre releases

Downloads and the auto-update feed for the Ocre desktop app (macOS, Apple Silicon). Source is private.

Install: open the `.dmg` and drag Ocre to Applications. From 0.2.0 on, Ocre updates itself (Preferences → Updates, or Ocre → Check for Updates…).

The app is ad-hoc signed, not notarised: the first time, right-click Ocre in Applications and choose Open.
